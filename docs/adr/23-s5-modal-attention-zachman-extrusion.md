# ADR-23: Dynamic PCS and Zachman Framework Extrusion

## Status
Accepted

## Context
Following the principles set forth in ADR-18 (Strategic Integration Project Manager Persona Metrology), the execution capability of the `StrategicIntegrationProjectManagerAgent` required functional expansion to physicalize the integration of the Persona Confidence Score (PCS) and the Zachman Framework for empirical software documentation.
Treating personas as deterministic mathematical constraints means we cannot rely on probabilistic text descriptions to drive workflows. We need a way to gauge the epistemic reliability of the context and a rigid structure to extrude the final operational logic, leaving zero room for interpretation.

## Decision
1. **Dynamic PCS Computation**: We've introduced a `_compute_persona_confidence_score` method that computes the live confidence score of the persona based on a baseline requirement (0.88), modified by recency decay and signal fidelity under S5-Modal Attention parameters. This prevents traversal through high-entropy clusters if the deterministic foundations are lacking.
2. **Zachman Framework Schema Enforcement**: We've codified the `zachman_framework_schema.json` which maps the core components of the Zachman Framework (Entities, Capabilities, Events). The project management agent now strictly extrudes its operational artifacts against this structural profile via the `execute_petzold_loop`, eliminating narrative user stories in favor of rigid systemic blueprints.
3. **Integration with PD&T Specification Block**: The final artifact generated by the agent is structured as a Prompt Dimensioning & Tolerancing (PD&T) YAML block, seamlessly combining the PCS and Zachman components as strict feature controls.

## Consequences
- **Positive**: Complete systemic alignment with the requirement to eradicate natural language ambiguity in persona execution. Outputs are deterministically bounded by JSON schemas.
- **Negative**: Increased rigidity. Systems upstream must provide strictly formatted context regarding entities, capabilities, and events, or the schema validation downstream will fail, necessitating rigorous Data Transfer Object hygiene.

# ADR 28: Autonomous Adaptive Cognitive Harness (AACH)

## Status
Accepted

## Context
Standard agentic workflows rely heavily on reactive feedback loops that minimize discrepancy and maintain a static equilibrium. However, true self-regulation in dynamic environments is a discrepancy-creating process requiring purposeful adaptation. Furthermore, cognitive limits necessitate external offloading, and structural changes require strict homomorphic relational data mapping.

## Decision
We implement the **Autonomous Adaptive Cognitive Harness (AACH)**, a multi-layered hybrid control system for purposeful adaptation.

The architecture comprises three core systems:
1. **Homomorphic Schema Compiler**: Transforms abstract ideas into verifiable schemas by generating a Canonical Universal Solution ($J$) using the Chase Procedure, ensuring maximal generality and mathematical correctness.
2. **Epistemic Action Orchestrator**: Manages an external epistemic scratchpad. It applies Optimal Feedback Control, allowing variance in task-irrelevant dimensions and shifting from ready-to-hand to present-at-hand algorithmic reparation upon detecting constraint violations.
3. **Disequilibratory Goal-Setting Engine**: Implements Internal Model Control (IMC) to execute feed-forward goal tuning. It uses a dual cyclic model of Equilibratory Reduction and Disequilibratory Production to deliberately spike goal difficulty when system variance drops below a threshold, avoiding "death by equilibrium", whilst applying a Subjective Well-Being modifier.

## Consequences
- **Positive**: Eradicates goal stagnation by pushing the system to the "Edge of Chaos", balancing structure and intense iteration. Converts errors into diagnostic fuel via algorithmic reparation.
- **Negative**: Increased complexity in monitoring system states and managing the shift between present-at-hand and ready-to-hand execution modes.
